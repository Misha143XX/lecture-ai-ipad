# Lecture AI iPad Preview 0.1
- Бесплатная PWA-оболочка для iPad (без сервера, логина, платных API).
- Архив локальных лекций, предметы и полнотекстовый поиск.
- Просмотр видео, импорт TXT / SRT / VTT и временные метки.
- Цитатный конспект и поиск фрагментов по вопросу.
- Предупреждения о лимитах браузерной памяти и невозможности записи Zoom в фоне.
- Демо-лекция для проверки.

Не является портом всех функций macOS Lecture AI 0.5 — распознавание речи из медиа пока не подключено.
