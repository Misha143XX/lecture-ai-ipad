# Lecture AI iPad — 0.3 (эксперимент)

- Старый конспект из случайно отобранных цитат заменён на **структурированный конспект**: обзор тем, тематические блоки, тезисы по порядку и числа/даты, каждое с привязкой ко времени (если есть).
- Новая отдельная кнопка **«Создать связный ИИ-конспект (бета)»**: бесплатно пробует небольшую локальную WebGPU-модель Qwen 2.5 0.5B, если iPad её поддерживает. Сотни МБ первой загрузки, возможны сбои и ошибки фактов.
- Существующие записи, тексты и хранение IndexedDB не мигрируют и не удаляются. Для старой лекции нажать «Собрать по темам».
- Исправлены некоторые проблемы узких колонок, обрезания заголовков и вкладок на iPad.
- Service worker теперь сначала проверяет обновления HTML/JS, сохраняя офлайн-резервную копию и прежние записи.

## Ограничения

Без локальной языковой модели учебный план остаётся **экстрактивным**: приложение не переписывает мысли своими словами. Даже в режиме ИИ нужно проверять факты, особенно имена и даты после Whisper Tiny.

Ни один режим не отправляет видео/расшифровку на сервер: браузер загружает только библиотеки и веса моделей из общедоступных CDN/репозиториев. Приложение ещё не тестировалось на реальном iPad в версии 0.3.
