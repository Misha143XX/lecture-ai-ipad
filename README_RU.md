# Lecture AI для iPad 0.3

Бесплатная PWA без App Store. Источник публикации: репозиторий `lecture-ai-ipad` в GitHub Pages.

## Обновление без потери записей

1. **Не удаляйте** приложение с главного экрана iPad и не очищайте данные Safari.
2. Распакуйте этот ZIP на Mac.
3. GitHub → `lecture-ai-ipad` → **Add file → Upload files**. Загружайте **содержимое** папки (без дополнительного уровня).
4. Убедитесь, что рядом с `index.html`, `app.js` появился новый **`localSummarize.mjs`**.
5. **Commit changes**. Публикация обновится на прежней ссылке.
6. Друг: откройте сайт в Safari, перезагрузите после завершения публикации. В приложении должен появиться `iPad · Preview 0.3`.
7. Откройте старую 15-минутную лекцию, «Конспект» → «Собрать по темам». Заново распознавать видео не требуется.

### Связный ИИ-конспект (дополнительный тест)

Кнопка «✦ Создать связный ИИ-конспект (бета)» попробует запустить локальную Qwen2.5-0.5B через WebLLM/WebGPU. Для первого запуска потребуются сотни мегабайт загрузки, свободная память и поддержка WebGPU. На некоторых устройствах запуск невозможен. Если модель не запустится, структурированный конспект останется на месте; не повторяйте загрузку, если iPad нагревается или перезагружает веб-приложение. Нужен стабильный Wi-Fi. **Платных API, аккаунтов ИИ и отправки видео на сервер нет.** При этом **библиотеки и веса модели скачиваются из внешних источников**.

Это эксперимент, а не гарантия. Небольшая модель может ошибаться, поэтому сверяйте готовый пересказ с временными метками и оригинальной записью.

## Важные ограничения

- Распознавание речи из видео (Whisper Tiny) остаётся экспериментальным и может ошибаться.
- В бесплатной браузерной версии нет фоновой записи экрана Zoom.
- GitHub содержит только исходники сайта, без личных записей и текстов.
- Важные лекции лучше сохранять отдельно: данные браузера могут удалиться при нехватке места или очистке истории.
