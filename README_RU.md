# Lecture AI iPad 0.4 — бесплатная связка с MacBook

## Что изменилось

- Whisper и библиотека на iPad продолжают работать локально.
- В разделе «Конспект» появилась обработка на MacBook, кнопка «Отложить» и проверка связи.
- Отправляется **только расшифровка и временные метки** после согласия пользователя. Видео/аудио не передаются.
- Связный конспект сохраняется в прежнюю лекцию на iPad, включая обновление после перезапуска.
- Когда MacBook без интернета — лекция остаётся локальной; пользователь запускает отправку вручную позже.
- Не требуется платная подписка или Apple Developer Program.

## Обновление GitHub Pages

1. Открой публичный репозиторий `Misha143XX/lecture-ai-ipad`.
2. `Add file` → `Upload files`.
3. Перетащи только **содержимое** папки `LectureAI_iPad_PWA_040` (файлы `index.html`, `app.js`, `sw.js`, `styles.css`, `icons/` и остальные). **Не загружай** папку `LectureAI_Mac_Bridge_040`, секретный ключ и личные лекции!
4. `Commit changes`; дождись зелёной галочки Pages.
5. Открой https://misha143xx.github.io/lecture-ai-ipad/ и проверь метку `iPad · Preview 0.4`.

## Как пользоваться

- Друг записывает лекцию системной записью экрана iPad и распознаёт её через Whisper в Lecture AI.
- Когда MacBook владельца доступен, он запускает `start_mac.command`, получает временный HTTPS-адрес и секретный ключ.
- Друг получает адрес и ключ по личному сообщению, вносит их в раздел «Конспект», ставит галочку согласия и нажимает «Обработать на MacBook».
- Если MacBook недоступен, нажимает «Отложить». Ничего не отправляется; для обработки нажимает кнопку позже.
- Если потеряна связь после создания задания, можно вернуться и проверить статус. После перезапуска MacBook старые задания в его памяти пропадают, поэтому потребуется отправить текст ещё раз.

## Важно о приватности

Обработка бесплатная, **но не полностью офлайн**: во время работы нужен интернет на обоих устройствах. Содержимое расшифровки идёт через **Cloudflare** по HTTPS и обрабатывается на MacBook владельца. Cloudflare — сторонний провайдер транспорта. Пригодно только для записей, которые друг вправе передавать владельцу MacBook. Публичный GitHub хранит лишь код, не ключ или лекции. Ключ хранится на устройстве друга, в его браузере, и его следует беречь.

Не очищай данные сайта на iPad, пока не экспортированы важные расшифровки.
