# Lecture AI iPad Preview 0.2 — экспериментальная локальная расшифровка

Зачем: в 0.1 можно было загрузить видео, но не было перевода речи в текст.

## Обновление на GitHub Pages
1. В репозитории `lecture-ai-ipad` → Add file → Upload files.
2. Загрузите **изнутри папки 02** следующие файлы в корень: `index.html`, `app.js`, `styles.css`, `sw.js`, `localTranscribe.mjs`, `manifest.webmanifest`, и папку `icons` (если она уже есть, можно не обновлять).
3. Важно: `index.html` должен оставаться в корне, не внутри вложенной папки.
4. Нажмите Commit changes. В GitHub Pages будет новая версия, возможно потребуется полностью закрыть и открыть веб-приложение или обновить страницу (из-за кэша Service Worker).

## Тест на iPad
1. Открыть Lecture AI → нужная лекция → вкладка «Расшифровка».
2. Прикрепить сохранённое видео, если его нет.
3. Выбрать «Русский» и нажать «Расшифровать видео».
4. Первый запуск загружает бесплатную модель Whisper Tiny от Hugging Face, нужен интернет (~50–100 МБ и зависимости). Видео не передаётся на сервер.
5. Сначала лучше проверить 1–2 минуты, затем 15 минут. **Не сворачивать** веб-приложение.
6. По завершении текст + цитатный конспект сохраняются в библиотеке.

## Ограничения
- Это эксперимент, тестированного на настоящем iPad запуска Whisper пока нет. В Safari может не хватить памяти или мощности.
- Файлы MOV с некоторыми аудиокодеками могут воспроизводиться, но не декодироваться Web Audio API. Пробуйте MP4, M4A или MP3.
- Если видео уже было сохранено в PWA 0.1, библиотека и запись останутся на месте, а новый функционал появится после обновления кэша.
- Пока поиск по цитатам, а не полноценные ответы LLM; ИИ-конспект в этой версии — подборка цитат.
- Системная запись Zoom по-прежнему производится отдельно средствами iPadOS; PWA не может захватывать другое приложение в фоне.
- Репозиторий GitHub публичный: **не загружайте приватные записи или расшифровки в репозиторий**.
- Локальные записи PWA зависят от браузерного хранилища. Сохраняйте важные материалы в Фото/Файлы и экспортируйте текст.
