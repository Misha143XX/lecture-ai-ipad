# Lecture AI — бесплатная iPad PWA, версия 0.1

Это **отдельное веб-приложение**, которое устанавливается на главный экран iPad. Бесплатно: никакого Apple Developer аккаунта, TestFlight, Xcode на iPad или еженедельной подписи.

## Что реально работает

- Импорт `.mov`, `.mp4`, `.m4a`, `.mp3` и других видео/аудиофайлов, поддерживаемых Safari.
- Библиотека по предметам, названиям и датам; поиск по содержимому расшифровки.
- Импорт готовой расшифровки `.txt`, `.srt`, `.vtt` (вместе с видео или позже).
- Переход к нужному моменту видео нажатием на метку в субтитрах.
- Бесплатный офлайн-конспект **из дословных цитат исходного текста** — без выдуманных фактов.
- Поиск подтверждающих фрагментов по вопросу (лексический поиск, **не нейросеть**).
- Скачивание текстовых материалов как `.txt`.
- Локальное хранение файлов и данных в IndexedDB браузера; оболочка сайта кешируется для повторного офлайн-открытия.
- Кнопка «Посмотреть демо» создаёт пример без личных данных.

## Чего в 0.1 пока НЕТ

- **Нет записи Zoom/Telegram из другого приложения на iPad.** Системная запись экрана — отдельный механизм iPadOS; его доступность и захват звука нужно тестировать на реальном iPad.
- **Нет распознавания речи непосредственно из аудио/видео на iPad.** Для конспекта требуется готовый TXT/SRT/VTT. Реальный Whisper/Qwen из Mac-версии сюда ещё не подключён.
- Нет облачной синхронизации. Лекции на разных устройствах **не синхронизируются**, сервер ничего не хранит.
- Нельзя обещать сохранение огромных видео в браузере: при нехватке места остаются название/текст, но медиа может быть доступно только до закрытия вкладки.

## Как БЕСПЛАТНО опубликовать по ссылке для друга

Для работы ссылки iPad нужен HTTPS-сайт. Бесплатный вариант — GitHub Pages (для бесплатного аккаунта репозиторий должен быть публичным). Код сайта будет публичным, **личные записи и тексты при этом не выкладываются**, поскольку приложение хранит их на iPad.

1. Открой https://github.com и войди в свой аккаунт (или создай бесплатный).
2. Нажми `+` → `New repository`, назови `lecture-ai-ipad`, выбери **Public**, `Create repository`.
3. Открой репозиторий → `Add file` → `Upload files`. Загрузи **содержимое папки** `LectureAI_iPad_PWA_01`, чтобы `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest` оказались в корне, а три PNG — в подпапке `icons/`. Изображения предпросмотра загружать не нужно.
4. Нажми `Commit changes`.
5. В `Settings` → `Pages` → `Build and deployment`: `Deploy from a branch`, выбери `main`, папку `/ (root)` → `Save`.
6. После публикации сайт обычно будет на `https://ТВОЙ-ЛОГИН.github.io/lecture-ai-ipad/`. Его можно отправить другу в Telegram.

> ВАЖНО: Не загружай сами лекции и конспекты в репозиторий GitHub. Только исходные файлы приложения.

## Как друг установит на iPad

1. Откроет ссылку **в Safari**.
2. Нажмёт кнопку **Поделиться** → **На экран «Домой»** → **Добавить**. Если предлагается «Открывать как веб-приложение», включит этот пункт.
3. Откроет новую иконку **Lecture AI** на главном экране.
4. **Только теперь** импортирует записи/тексты. У Safari и веб-приложения на домашнем экране могут быть разные хранилища.

Не требуется повторная установка каждые 7 дней. Но очищение данных сайта, переустановка PWA или нехватка памяти могут удалить локальный архив — сохраняйте исходные лекции в «Файлы» или резервной копии.

## Локальная проверка на Mac до публикации

Из Терминала:

```bash
cd ~/Downloads/LectureAI_iPad_PWA_01
bash ./start_local.command
```

Откроется `http://localhost:8765`, где можно проверить приложение. Чтобы остановить локальный сервер — `Control + C` в Терминале.

Самостоятельное открытие `index.html` через Finder может не дать корректной работы офлайн-хранилища; используйте сервер выше.

## Приватность и ограничения

Сам сайт статический, **нет API и автоматической передачи файлов**. Не следует использовать общедоступный или чужой iPad для конфиденциальных записей. При записи занятий предупредите участников и учитывайте правила школы/университета и применимое законодательство.

## Технически

HTML / CSS / JavaScript, без внешних библиотек и платных API. В Chrome отлажены функции обработки текстов; на реальном iPad работу видео и ограничения браузерного хранилища потребуется проверить. Проект FIN2 и Mac-приложение Lecture AI не изменяются.
