# Lecture AI iPad 0.3.2 — точечный тест запуска CPU-модели

Скриншот с iPadOS 18.4.1 показал, что в 0.3.1 по-прежнему возникала ошибка `requested maxComputeWorkgroupStorageSize = 32768, limit = 16384`. В 0.3.2 код создания конспекта **вообще не обращается к WebGPU / WebLLM**. Он импортирует ONNX-модель Qwen напрямую через Transformers.js и запускает её в `device: wasm`.

## Обновление GitHub Pages
1. Распакуй ZIP, открой GitHub `Misha143XX/lecture-ai-ipad` → Add file → Upload files.
2. Перетащи **содержимое** папки 0.3.2, не папку и не ZIP. Подтверди замену старых файлов и нажми Commit changes.
3. Проверь публикацию через Actions и открой сайт в обычном Safari. Метка версии: `iPad · Preview 0.3.2`.
4. Открой существующую лекцию → Конспект → «Создать связный ИИ-конспект». Ничего заново расшифровывать не надо.
5. Если появится ошибка, пришли **текст под кнопкой**, включая слова `CPU-модель`.

Не удалять приложение, записи и данные Safari. Не загружать личные видео в публичный репозиторий.

## Ограничения
- Проверяется лишь запуск CPU-модели на этом iPad, а не качество полного учебного конспекта.
- Первая загрузка требует интернета; после неё обработка задумана локальной.
- Работа в Safari может быть медленной или прерваться из-за нехватки памяти.
- До успешного реального теста функция остаётся экспериментальной.
